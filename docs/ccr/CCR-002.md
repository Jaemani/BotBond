# CCR-002

> 원래 CCR-001로 작성했으나 B의 CCR-001(executable-backend-supporting-types, 2026-08-02 accepted)과 번호 충돌로 CCR-002로 재번호.

- **Requester:** 역할 C (Solana)
- **Affected contract:** docs/03-contracts.md §5 `BondSession` account 구조
- **Current limitation:** PDA seeds가 `["bond", agent, policy_hash, session_nonce]`인데 account에 `session_nonce`가 없으면 close/settle/reclaim 시 클라이언트가 nonce를 별도 보관해야 하고, account만 보고 세션을 재파생할 수 없다.
- **Decision:** Accepted — 2026-08-03 통합 기준으로 `BondSession`에 `session_nonce: u64` 필드를 `expires_at` 다음, `status` 앞에 둔다. 후속 instruction은 저장된 nonce로 PDA seeds를 검증한다.
- **Breaking impact:** account 레이아웃 +8 bytes. 기존 raw account 소비자는 없었고 IDL 소비자는 재빌드로 반영한다.
- **Migration:** 첫 배포 전 변경이라 계정 migration은 없다.
- **Implementation evidence:** Rust account/PDA 검증, TypeScript `BondSessionView`/`deriveBondPda()`가 같은 nonce를 사용하며 local-validator contract tests가 검증한다.
